# StoreLens — прежде чем платить

StoreLens — сервис предварительной проверки интернет-магазинов перед покупкой. Он помогает собрать доступные сведения о сайте и продавце, увидеть основания для доверия и понять, на что обратить внимание перед оплатой.

## Принцип работы

1. Пользователь указывает ссылку на интернет-магазин.
2. Сервис сопоставляет доступные сведения о сайте, истории его адреса и продавце.
3. Пользователь получает понятный отчёт с выводами, источниками и ограничениями проверки.

Результат носит предварительный характер: полнота проверки зависит от доступности сведений. Недостаток данных сам по себе не означает, что магазин мошеннический.
